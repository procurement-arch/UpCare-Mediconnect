#1. Project Overview

UpCare MediConnect is a web-based care marketplace and clinical workspace that connects patients with five categories of care providers through a single account, a single booking flow and a single messaging layer.

The platform combines three things that are usually separate products: a provider directory and appointment booking engine, a clinical workspace for providers (notes, prescriptions, availability, earnings), and an AI layer for triage and mental-health screening.

#1.1 Goals

  • Give patients one place to find a doctor, therapist, caregiver, childcare provider or special-needs specialist.
  • Give every provider type the same panel, differentiated by provider type and specialization rather than by separate apps.
  • Enforce booking correctness on the server so double-booking and out-of-hours requests are impossible.
  • Use AI to help patients describe symptoms and understand their mental health before they ever see a clinician.
  • Support multilingual, mobile-first access with light and dark themes.

#2.5 Security Model

  • Row Level Security is enabled on every public table; access is granted explicitly per role.
  • Roles live in a dedicated user_roles table and are checked through a security-definer has_role() function, preventing privilege escalation.
  • Doctors can only read profiles of patients with an active care relationship.
  • Mental-health data is separated: raw AI chats stay private to the patient, only structured clinical output is shareable.
  • Access to mental-health records is written to an append-only audit log protected by a restrictive policy.
  • Realtime subscriptions are authorized per topic, so users cannot listen to other users' channels.
  • Leaked-password protection (HIBP) is enabled on authentication.

#3. Core Features

#3.1 Unified Provider Taxonomy

All care professionals share one provider panel. A single provider_type field distinguishes them, and specialization refines the listing.

Provider typeTypical specializations
DoctorCardiology, paediatrics, dermatology, general medicine and other departments
TherapistClinical psychology, counselling, CBT, family therapy
CaregiverAdult day care, home nursing support, senior care, post-operative care
ChildcareInfant care, after-school care, nanny services
Special needsAutism support, developmental therapy, behavioural support

#3.2 Unified 3-Step Booking

Every service uses the same wizard, reached at /book?type=<provider type>. The flow is deliberately fixed at three steps.

  1. Choose provider and service — real providers pulled live from the database, with a per-type service catalogue priced in Bangladeshi Taka (৳).
  2. Pick date and time — calendar plus available slots derived from the provider's published availability; in-person or virtual visit.
  3. Confirm — summary card, optional notes, then confirmation with an automatic redirect to the appointments list.

Server-side validation, implemented as a database trigger, independently enforces:

  • The requested slot falls inside the provider's published availability for that weekday.
  • No overlapping appointment exists for the provider.
  • No overlapping appointment exists for the patient.
  • Cancelled appointments are ignored when checking conflicts.

Friendly messages such as “This slot was just booked” are shown instead of raw database errors. Because the rules live in the database, they hold even if the client is bypassed.

#3.3 Confirmation Timeline

Every status change is recorded automatically with a timestamp and the acting role. On the appointments page each row expands to a colour-coded vertical timeline showing requested, confirmed, completed or cancelled states, with the latest entry marked Current.

#3.4 AI Triage Assistant

  • Conversational intake that asks about symptoms, duration and severity.
  • Recommends a care level and the most suitable provider type.
  • Hands off into the booking wizard with the recommended type preselected.

#3.5 AI Mental Health Screening (Aria)

Instead of presenting questionnaire cards, Aria holds an adaptive conversation, asks follow-up questions based on the answers given, and then proposes likely areas of concern with a confidence indication and next-step guidance.

Conditions Aria can surface: depression, generalized anxiety, panic, stress, insomnia, adult ADHD, autism-spectrum traits, bipolar patterns, PTSD, OCD, alcohol or drug misuse, and eating concerns.

Raw conversations remain private to the patient. Only the structured clinical summary can be shared with a therapist, and every access is audited.

#3.6 Mental Health Toolkit

  • Mood tracker with AI-generated trend insights.
  • Journal with sentiment and theme analysis.
  • CBT companion for guided thought-record exercises.
  • Safety plan builder with an always-visible crisis banner.
  • Exportable mental-health record (PDF) with consent gating.

#3.7 Provider Workspace

  • Availability editor defining weekday time windows that drive bookable slots.
  • Client list built from active care relationships.
  • Clinical notes tied to patient and appointment.
  • Prescriptions with a printable standard Rx template and auto-issued numbers (for example RX-2026-0001).
  • Realtime messaging with patients.
  • Earnings dashboard and resource library.

#3.8 Diagnostics Portal

  • Service catalogue and pricing management.
  • Booking queue with many-to-many service lines per booking.
  • Result upload plus AI plain-language interpretation.
  • Follow-up tracking and booking analytics.

#3.9 Admin Console

  • Create provider accounts directly, with type and specialization.
  • Approvals and credential verification queues.
  • Patient management, service catalogue, appointments oversight.
  • Analytics, reports and support inbox.

#3.10 Platform-Wide

  • Four languages: English, Arabic, Bengali and Hindi.
  • Light and dark themes persisted per device.
  • Realtime notifications generated by database triggers.
  • Secure medical-record storage and retrieval.
  • Responsive layout with a dedicated mobile bottom navigation.
  • Global React error boundary so a single failing view never blanks the app.

#4. User Manual

#4.1 Getting Started

  1. Open the platform at https://upcaremediconnect.rufpaa.org.
  2. Choose Sign Up to create an account, or Log In if you already have one.
  3. On sign-up, select whether you are a Patient or a Provider.
  4. Providers additionally choose a provider type (doctor, therapist, caregiver, childcare, special needs) and enter their specialization.
  5. Confirm your email, then sign in. You can also sign in with Google.

Tip: if you clicked a Book button before signing in, you are returned to that exact booking page after login rather than to the dashboard.

#Forgot your password

  1. Click Forgot Password on the login screen.
  2. Enter your email address and submit.
  3. Open the reset link from your inbox and choose a new password.

#4.2 Patient Guide

#Finding care

  1. From the landing page open Services and pick the service you need.
  2. Browse the provider cards. On the therapist page each card shows an AI match score; open the explanation panel to see the exact factors behind it.
  3. Click a provider to open their full profile, or click Book to jump straight into the wizard.

#Booking an appointment

  1. Step 1 — confirm the provider and choose a service; the price and duration are shown.
  2. Step 2 — pick a date on the calendar, then choose an available time slot and select in-person or virtual.
  3. Step 3 — review the summary, add any notes for the provider, and confirm.

If a slot is rejected, either it was taken moments earlier or it falls outside the provider's working hours. Choose another slot on the same day or try the next available day.

#Managing appointments

  • Open Appointments from the sidebar to see all upcoming and past visits.
  • Click the chevron or Timeline on any row to expand its confirmation timeline.
  • Use Reschedule or Cancel on upcoming appointments.
  • Virtual visits are joined from the appointment row at the scheduled time.

#Using the AI Triage Assistant

  1. Open AI Triage from the dashboard or the sidebar.
  2. Describe your symptoms in your own words and answer the follow-up questions.
  3. Read the recommendation panel, then use its Book button to continue into the wizard with the right provider type preselected.

#Using AI Mental Health Screening

  1. Open Mental Health, then Screening.
  2. Chat with Aria; answer as openly as you can — the questions adapt to your answers.
  3. Review the summary of likely areas of concern and the suggested next steps.
  4. Choose whether to share the structured summary with a therapist. Your raw conversation is never shared automatically.

If you are in immediate danger, use the crisis banner shown at the top of every mental-health page.

#4.3 Provider Guide

#First-time setup

  1. Sign in; you land on the Provider Dashboard. The sidebar shows your provider type, not a generic label.
  2. Open Availability and set your working weekdays and time windows. Until you do this, patients cannot book you.
  3. Complete your profile details and specialization so you appear correctly in search.

#Daily workflow

  • Dashboard — today's schedule, pending requests and quick actions.
  • My Clients — patients with an active care relationship.
  • Care Notes — write and review clinical notes per patient or appointment.
  • Prescriptions — write a prescription, preview the printable template and print or save it.
  • Messages — respond to patient conversations in realtime.
  • Earnings — track completed visits and revenue.

#Writing a prescription

  1. Open Prescriptions, or use the Write Prescription quick action on the dashboard.
  2. Select the patient from your client list.
  3. Enter the diagnosis, then add each medication with dose, frequency and duration.
  4. Add advice or follow-up instructions and save. A prescription number is issued automatically.
  5. Open the saved prescription to preview the standard Rx template and print it.

If the patient list is empty, no active care relationship exists yet — it is created when the patient books you.

#4.4 Diagnostic Staff Guide

  1. Sign in to reach the Diagnostic Dashboard.
  2. Under Services, maintain the test catalogue and pricing.
  3. Work the Bookings queue; each booking may contain several service lines.
  4. Upload results under Results; the AI interpretation gives patients a plain-language explanation.
  5. Track outstanding actions under Follow-ups and review volume under Analytics.

#4.5 Admin Guide

  1. Sign in to reach the Admin Dashboard.
  2. Providers — filter by provider type, review listings, and use Add Provider to create an account directly with type, specialization and initial password.
  3. Approvals and Verifications — process pending provider applications and credential checks.
  4. Patients — look up and manage patient accounts.
  5. Services — maintain the platform-wide service catalogue.
  6. Appointments — oversee bookings across all providers.
  7. Analytics and Reports — monitor platform usage and export summaries.
  8. Support — handle incoming user requests.

#4.6 Preferences

  • Language — switch between English, Arabic, Bengali and Hindi from the navigation bar; the choice is remembered.
  • Theme — toggle light and dark mode; the choice is stored per device.
  • Notifications — realtime alerts appear in the bell panel as bookings and messages arrive.

#4.7 Troubleshooting

#5.2 Running the Project Locally

Node.js and npm are the only prerequisites.

  • npm i — install dependencies
  • npm run dev — start the development server with hot reload
  • npm run build — create a production build
  • npm run lint — run ESLint
